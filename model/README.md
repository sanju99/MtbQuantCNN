# Descriptions of Model Files

3. <code>dataloader.py</code>: Creates the <code>MtbGeneDataset</code> class to load data in batches for the CNNs.
4. <code>cnn_custom_loss.py</code>: Trains a CNN with early stopping using the bounded loss function.
